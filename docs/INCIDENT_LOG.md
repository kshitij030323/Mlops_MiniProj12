# Incident log

These are real failures hit while building and testing the system (2026-10-29), not hypotheticals.

| # | When | What happened | Detection | Root cause | Fix | Follow-up |
|---|---|---|---|---|---|---|
| 1 | 2026-10-29, first eval run | The evaluation batch crashed before any scenario ran: `ValueError: 'draft' is already being used as a state key` | Traceback from `python -m eval.run_eval` | The LangGraph node was named `draft`, the same as a key in `RunState`. LangGraph forbids that because node outputs and state channels share a namespace | Renamed the node to `draft_determination` | Node names and state keys are now distinct by convention (verbs for nodes, nouns for state) |
| 2 | 2026-10-29, eval run 1 | Only 12/24 scenarios routed correctly. 11 correct drafts (including the 4.1 case) were **escalated** by self-verification with `basis_not_grounded` (groundedness 0.39–0.58) | Eval output, `verify` steps in traces | The groundedness check counted only cited passages as support. Facts from the complaint itself (product "fixed deposit", the entity name) were scored as ungrounded claims, so every correct draft that named the product failed | `verify()` now also accepts facts from the request's own fields. Basis templates restate the cited passages | The system failed safe: no wrong answer was returned, only too many escalations. Route accuracy 0.50 → 1.00 after the fix (stub). Escalation precision is now tracked in the eval summary |
| 3 | 2026-10-29, eval run 1 | Mean tool calls per run reported as 3.3, though traces showed 6–8 calls | Mismatch between `mean_tool_calls` and traces | Each verification retry granted extra budget by *decrementing* `tool_calls`, which corrupted the per-run tool-call metric (A6) | Retries now add to a separate `tool_bonus` budget, and `tool_calls` only increases | |
| 4 | 2026-10-29, breaker demo | Degraded runs lost their provisional route: the API returned `provisional_route: null` though the worker had computed `refer_to_other_regulator` | Manual check during circuit-breaker test (stub `mode=down`) | The `Determination` response model had no `provisional_route` field, so pydantic dropped it when serialising `RunResult` | Added `provisional_route` to the contract (documented as *not issued*) | Contract schemas are re-exported with `scripts/export_contracts.py` |
| 5 | 2026-10-29, first Docker build | `docker compose build` failed after ~75 min: `ReadTimeoutError: files.pythonhosted.org … Read timed out` (twice) | Build output | Pip downloads inside the Colima VM ran at ~0.25 MB/s (host: ~1.4 MB/s), and pip does not resume an interrupted download. Compose was also building the same image once per service, in parallel, because every service had a `build:` section | Only `indexer` builds the shared image. Added optional `wheels`/`hfseed` build contexts (host-side wheelhouse, installed with `--no-index`) and a pip cache mount. Build time dropped from >75 min (failed) to <1 min for the dependency layer | README "Slow network" section |
| 6 | 2026-10-29, first `docker compose up` | `up` rebuilt the image instead of using the one just built, and failed with the same PyPI timeout | `up` output | `pull_policy: build` on the indexer forces a rebuild on every `up` | `pull_policy: missing` (build only if the image is absent) | |
| 7 | 2026-10-29, Docker eval | `python -m eval.run_eval` inside the worker printed 24 results and then failed to save them | `docker compose cp` found no results file | Containers run as non-root `app`, but `/app/eval/results` was owned by root (`PermissionError`). The README command could not have worked in Docker | `chown app /app/eval` in the Dockerfile | Re-ran in Docker: 24/24, metrics identical to local |
| 8 | 2026-10-29, Jaeger check | Verifier spans appeared as a separate trace instead of under the run | Jaeger: run trace had only `api` and `agent-worker` | The worker forwarded `X-Correlation-ID` but not the W3C `traceparent` header to the verifier | Inject the OTel context into the verifier request headers. One trace now spans api → agent-worker → verifier (37 spans) | |
